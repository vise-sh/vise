# Contributing to vise

Thanks for your interest in contributing to vise! This guide is a placeholder and will be expanded with details on setting up a development environment, running the server and CLI locally, coding conventions, and how to submit changes. In the meantime, feel free to open an issue or pull request on GitHub, and check the `Justfile` in the repository root for the common development commands (database setup, running the server, generating the OpenAPI spec).
